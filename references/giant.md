# 巨物与尺度库

尺度是想象力放大器。先写参照物的真实尺寸，再写人物与它的接触点，最后写相机放在哪一侧。不要只说「巨大」。

## 模式

- NORMAL — 人体与家具符合日常比例
- GIANT_PERSON — 人物像都市巨人，建筑到胸口或膝下，手可撑楼顶或栏杆
- GIANT_PROP — 杯子、键盘、书、墨镜变成建筑尺度，人物正常或偏小，靠在杯沿、坐在键帽上
- MINI_PERSON — 手办尺度的人站在键盘、书桌、咖啡泡沫上
- SURREAL_MIX — 人物半巨物半日常，例如头正常、身后城市缩成模型，或腿能踩进茶杯

## 写入句式

```
Scale mode: [mode]. Real-world anchor: [object] is the size of [comparison]. Contact point: the character [leans on / sits on / holds / towers over] [exact part]. Camera is [on the desk / at street level / inside the cup]. Keep anatomy consistent with the chosen doll ratio.
```

## 稳比例的参照

- 巨型咖啡杯：人物下巴抵在杯沿，杯口宽度约等于肩宽的 1.2–2 倍
- 微缩键盘：人物坐在空格键或掌托上，键帽大于脚长
- 城市巨人：最近的楼到胸口，远处楼群到腰，地平线在画面下三分之一
- 巨型服装：外套领子高过正常人的一层楼（仅限 SURREAL）

## 禁忌

不要写「tiny cute child body」来做微缩。微缩的是尺度，不是年龄。人物仍是同一成人身份。
